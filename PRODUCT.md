# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Hiring managers and clients exploring Alejandro Frank's engineering projects.

## Product Purpose

Let visitors inspect the work and understand its engineering decisions through short playable examples. Reading the project remains available without playing.

## Capabilities and Constraints

The portfolio arcade has seven project slots. The Agents in GCP slot illustrates coordination with synthetic orders; it does not run the Python agents or make live AI or GCP calls. Games use plain JavaScript and CSS and retain keyboard, mobile and reduced-motion access. Preserve other games and the existing navigation.

## Brand Commitments

Use plain language, compact titles and inspectable evidence. Agents in GCP uses the existing warmer demo style. Madrid delivery is the example, not the scope of the engineering capability. Credit gameplay inspirations without copying their art.

## Evidence on Hand

Project case studies, source links, recorded Madrid city/store data and agent configurations are present in this repository. Game scores are synthetic; never describe them as real model evaluation or cloud cost results.
